<h1 align="center">Obsidian Lumines</h1>

<p align="center">
  <a href="https://github.com/danielkhmara/obsidian-lumines">Star me on GitHub</a> ⭐ <a href="https://github.com/danielkhmara/obsidian-lumines/issues">Report an issue</a>
</p>

<img src="assets/theme-preview.png" alt="Obsidian Lumines theme preview">

<p>
  Obsidian Lumines has been in development since 2024 and is used by thousands of people. The theme refines the default look of Obsidian and keeps all interface elements in a single style. It works on Windows, macOS, iOS and Android and supports the Style Settings plugin for additional customization.
</p>

<p>
  Lumines is developed on <a href="https://obsidian.md/help/Catalyst+license">Obsidian Catalyst</a> early access builds. Each new build is tracked, so fixes and support for new features are prepared before the public release, and after an Obsidian update you usually do not have to wait for a theme update. The theme is free and open source under the MIT License.
</p>

<h2>Metadata Icons</h2>

<img src="assets/feature-preview-metadata-icons.png" alt="Metadata Icons">

<p>
  Metadata Icons make the Properties panel easy to read at a glance. The theme includes more than 900 icons from <a href="https://tabler.io/icons">Tabler Icons</a>, each matched to a property name.
</p>

<p>
  To show an icon, add a property to a note and give it a name from the <a href="metadata-icons.md">list of supported names</a>. Obsidian stores properties as YAML at the top of the file. The icon appears instantly and updates when the property is renamed.
</p>

<p>
  Properties outside the list still get an icon, chosen by type: text, list, number, checkbox, date or date with time. These native icons are redesigned too. This feature requires Obsidian 1.4.5 or newer.
</p>

<h2>Custom Checkboxes</h2>

<img src="assets/feature-preview-custom-checkboxes.png" alt="Custom Checkboxes">

<p>
  The native checkbox has a redesigned icon, and the theme adds 36 custom states. Each state has its own icon and a color that matches its meaning, so a task list is easy to scan.
</p>

<p>
  A checkbox is a list item with square brackets after the dash: <code>- [ ]</code>. Put a symbol inside the brackets to choose the state, for example <code>- [+]</code> or <code>- [!]</code>. Uppercase and lowercase symbols are different states.

<h2>CSS Classes</h2>

<img src="assets/feature-preview-css-classes.png" alt="CSS Classes">

<p>
  Add classes to the <code>cssclasses</code> property of a note to change how that note looks. Bold text, italic text and the quote bar can be recolored in 13 colors, for example <code>bold-yellow</code>, <code>italic-blue</code> and <code>quote-violet</code>.
</p>

<p>
  Headings from h1 to h6 can be centered, aligned to the end or recolored, for example <code>h1-center</code>, <code>h6-end</code> and <code>h3-red</code>. Bold, italic and quote classes also have short forms that start with <code>b-</code>, <code>i-</code> and <code>q-</code>.
</p>

<h2>Style Settings</h2>

<img src="assets/feature-preview-style-settings.png" alt="Style Settings">

<p>
  The theme supports the <a href="https://github.com/mgmeyers/obsidian-style-settings">Style Settings</a> plugin. Once it is installed, the theme gets its own section in the plugin settings, where you can choose a font for the vault, recolor folder names, adjust header padding, hide interface buttons and change the order of buttons in the mobile navigation bar. Russian is supported, and all options are listed in the plugin itself.
</p>

<h2>How to Install</h2>

<ol>
  <li>Open <b>Settings</b>.</li>
  <li>Go to <b>Appearance</b>, then <b>Themes</b>, and select <b>Manage</b>.</li>
  <li>Select <b>Lumines</b> in the list of community themes.</li>
  <li>Select <b>Install and use</b>.</li>
</ol>
