# Metadata Icons

Supported property names for the Metadata Icons feature of the Lumines theme. The icons come from [Tabler Icons](https://tabler.io/icons) in the outline style.

## How It Works

Add a property to a note and give it one of the names below. The icon appears next to the property right away.

A property whose name is not in the list gets an icon by its type: text, list, number, checkbox, date or date with time.
